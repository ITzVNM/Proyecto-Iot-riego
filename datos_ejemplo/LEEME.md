# Datos de ejemplo

Coloque aquí una muestra (por ejemplo, un día) de los archivos que genera el sistema:

- `crudo/nodoN_<rol>_AAAA-MM-DD.csv`: lecturas crudas por nodo.
- `promedios_5min/nodoN_<rol>_AAAA-MM.csv`: promedios de 5 minutos.
- Un extracto del respaldo `telemetria_AAAA-MM.jsonl`.

Las columnas (con sus unidades) están en la primera fila de cada CSV. Separador `;` y coma decimal, para Excel en español.
